# PC OS AI Dock 交互 Demo

**[点击打开在线体验](https://kingangbian-prog.github.io/pc-ai-dock-demo/)**

无需登录、安装或启动本地服务。请使用上面的 GitHub Pages 地址；仓库页面展示的是源码。本仓库及其源码公开可见。

## 可体验内容

- 普通 / AI Dock 手动切换，440ms 翻面与淡彩虹玻璃底板。
- 小艺作为默认指令助手；四个固定 Agent：Workbuddy、千问、豆包工作、ChatGPT。
- 每个 Agent 至少三项不同的模拟任务；鼠标悬停展示横向任务卡片，点击打开准确任务。窄屏可横向滚动，支持键盘导航。
- Bot 中的独立 Goals 长期会话和按目标归属的输出版本。
- 小型 AI 实况进度卡片及当前任务的补充输入。
- 模拟 Computer Use：请求接管 → 暂停 ACK → 人工编辑 → 交还 ACK → 沿用同一任务与上下文。
- 同图标再次点击收起界面，任务不会取消；重复打开保留草稿内容。

## 模拟与本地保存

所有任务、授权、语音、账号连接及 Computer Use 都是模拟。没有真实 Agent、邮箱、微信、飞书或 OS 自动化，不录音、不上传本机资料、不修改真实系统 Dock。

访客会从合成的演示数据开始。会话、任务和草稿仅保存在该访客自己的浏览器 localStorage，不存在共享数据库或账号后台。清除该站点浏览器数据会清除该浏览器的演示记录。本仓库不含制作者浏览器历史、真实会话、账号数据或本地证据截图。

图标使用演示字标，非官方品牌标志；壁纸为概念原型生成素材。

## 本地运行源码（可选）

需要 Node.js 20 或更新版本，无第三方依赖，无需 npm install：

```sh
npm start
```

随后在当前电脑打开 http://127.0.0.1:4173/ ，保持终端运行。在线访客无需执行这些步骤。

## 发布方式

GitHub Pages 从 main 分支仓库根目录发布，.nojekyll 保持静态文件原样提供。模块、样式和壁纸均使用相对路径，兼容 /pc-ai-dock-demo/ 项目子路径。浏览器无需构建步骤或后端服务。
